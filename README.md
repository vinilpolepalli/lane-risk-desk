# Lane Risk Desk

Demo built by Vinil Polepalli (vinilpolepalli.com) as a project for Ekho Labs (ekholabs.com).

Turns a cited ocean-lane disruption into a concrete PO-level reroute decision: pick a lane, enter a PO value and delivery window, and a deterministic engine scores the original routing and each alternative. Costs are labeled estimates; disruption facts are cited. Independent demo, not affiliated with Ekho Labs.

Static export of a Next.js app. Built with Claude Code.
