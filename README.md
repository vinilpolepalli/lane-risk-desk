# Lane Risk Desk

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Ekho Labs (ekholabs.com) works in. Not affiliated with or endorsed by Ekho Labs.

A worked example of what a reroute decision layer could look like: pick a lane, enter a PO value and delivery window, and a deterministic model scores the original routing against alternatives. Lane statuses are scenario assumptions set for illustration, not live carrier availability. Costs are labeled estimates; scenario background items are dated and cited.

Static export of a Next.js app. Built with Claude Code.
